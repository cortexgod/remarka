## Задача
Верни один JSON-объект строго такой формы (значения — пример формата, не содержания):

{
 "meeting_type": {"type": "pitch", "confidence": 0.85, "reason": "одно предложение"},
 "structure": {"kept": false, "comment": "1–3 предложения с таймкодами"},
 "questions": [
  {"t": 28.5, "asked": "формулировка вопроса собеседника", "answered": "off_topic", "comment": "что ответил и куда ушёл"}
 ],
 "jargon": [
  {"t": 12.0, "term": "термин", "comment": "как сказать проще"}
 ],
 "three_things": [
  {
   "title": "до 60 символов, глаголом",
   "why": "1–2 предложения с опорой на числа/события",
   "quote": "дословная цитата из моих реплик, 4–20 слов подряд",
   "instead": "готовая формулировка, что стоило сказать",
   "metric": "layer1.filled_pauses_per_min"
  }
 ]
}

Допустимые значения: `meeting_type.type` — pitch | demo | sales | interview | standup | lecture | one_on_one | training | other; `answered` — on_topic | partial | off_topic | not_answered; `metric` — ключ из блока «Метрики» или null. Таймкоды `t` — числа в секундах. Никакого текста вне JSON.
